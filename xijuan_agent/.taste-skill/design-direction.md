# 智能体工作台界面方向

## 使用场景

文档分析人员输入已处理文件的 `file_id` 和问题，观察模型如何检索文本、选择章节/表格、读取 PDF 页图，再核对最终回答。

## 设计决定

- 采用桌面优先的双栏研究工作台：左栏显示当前文档和可用证据工具，主栏显示连续迭代时间线与流式回答。
- 文件选择器从现有 complete 文件列表搜索、多选后把引用标签加入当前消息；引用不会自动带到下一条消息。
- 对话在浏览器内存中持续追加；工具调用作为默认收起的证据轨迹附在对应回答下，不显示轮次编号。
- 上下文超出阈值时保留最近工具证据，并用同一 Agent 模型压缩较早结果；刷新页面后不恢复会话。
- 使用高对比白底、石墨文字、青绿操作色并辅以暖橙状态色；边框和浅灰底承担分组，不使用装饰性渐变或背景图。
- 小屏切换为单列，文档信息与工具列表压缩到上方，时间线保留主要空间；输入区在底部保持可达。

## 验收重点

- 文字 token 连续追加，工具调用与结果按实际到达顺序出现。
- `pdf_reader` 返回的页码标签与图片同时显示。
- 每条消息可引用多份文件，合并检索结果必须保留来源文件信息。
- 中止后停止读取流，重新开始会清空本次页面的过程。
- 桌面和窄屏均无重叠、横向溢出或内容被固定输入区遮挡。
