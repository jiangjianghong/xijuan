# 析卷智能体界面设计记录

## 产品与任务

页面回答的首要问题是：“我可以怎样把这些 PDF 变成有原文依据的结论？”

真实对象包括已处理 PDF、持续引用范围、问题、连续回答、工具调用、检索结果、原始页图、后台摘要与上下文估算预算。支持 20 份文档及 12 种研究工具，没有虚构历史对话、业务指标、账户或模型选项。

## 视觉方向

- 本轮采用 Editorial greeting，抽取种子 `1028258708`，记录位于 `redesign/direction.json`，保留项目现有本地 Nunito / Lora 字体与绿色品牌方向。
- 选择“文档纸张”作为产品视觉：雾灰资料栏、纸白阅读画布、墨绿文字与操作色；专属三层卷页标识在品牌区和初始状态中呼应。
- 中央阅读轴线承载欢迎、快捷问题、消息与输入。1440px 下分配 264px 资料栏、1166px 画布及 10px 外边距，回答和输入共用 820px 宽度。聊天内容需要可读行长，因此不采用仪表盘的 KPI 网格与宽表格模板。
- 资料为稳定上下文，检索过程为辅助证据，最终回答是视觉中心。12 种工具放在可展开目录；每轮研究完成后自动折叠证据，用户手动展开的状态保留。
- 手机和平板以对话为主，资料从左侧抽屉进入；输入始终留在独立网格行，内容只在自己的区域滚动。

## 动效与状态

用户明确强调动效质量，因此在通常只保留反馈动效的应用规范之外，给欢迎标识增加一次性 SVG 描边，并让标题与快捷提问轻量错峰进入。动作不阻塞操作；悬停、按压、附件进入、工具记录、抽屉与 dialog 使用统一曲线。循环仅用于真实执行状态，结束即停止；减少动态效果偏好下全部关闭。

## 验证记录（2026-11-17）

- 浏览器实测 1440、768、390、320px，初始与对话状态均无页面横向溢出，输入区不遮挡阅读区。
- 在独立无头浏览器中对现有 `/agent` 页面注入明确标记的测试响应，验证多文档选择、快捷问题、完整 SSE、Markdown 表格、证据展开、连续追问、中止、移动抽屉、焦点恢复与新研究清空；复制与导出通过隔离剪贴板和下载验证原始回答、引用文档及完整问答内容，未向真实模型发起研究请求。
- 浏览器控制台无异常，减少动态效果下动画数量为 0。
- 设计检查从旧版 2 项失败、3 项警告改善为 0 项失败、1 项警告。剩余提示为初始页面辅助文字占比偏高：正文与输入 14px，功能标签 13px，说明和元信息 11–12px；没有低于 11px 的可读文字，文本对比度通过。
- 47 项前端测试全部通过，回归测试覆盖旧请求隔离、检索竞态、跨搜索选文档、20 份限制、SSE 分块、异常断流、Markdown 转义及特殊表格单元格。代码审查指出的表格丢列与旧工具错误错位均已修复并有回归测试。

测试文档与回答只存在于隔离浏览器的验证脚本中，生产页面没有内置样例数据。截图和浏览器断言保留在被忽略的 `.auth-checks/agent-ui/`。
