# 并发池实时监控独立原型设计

## 目标

制作一个可直接在浏览器打开的独立 HTML 页面，用模拟数据展示当前项目各并发池的实时状态。页面只读，不允许修改并发配置；重点通过竖向容量塔、灰色排队条和连续动画表达占用、空闲、排队与瓶颈。

## 页面结构

页面采用浅色专业监控台风格，保持高信息密度和充分留白，不使用传统卡片矩阵。

1. 顶部状态栏：产品名、模拟连接状态、最近更新时间、暂停/继续和手动刷新按钮。
2. 摘要带：运行槽位、排队任务、饱和池数量、P95 等待时间，作为一条连续指标带展示。
3. 主监控画布：按“模型通道”“业务阶段”“单任务限制”“管线调度”分组并排展示 ECharts 竖向容量柱。
4. 底部压力轨道：展示最近 60 秒总体压力曲线、实时事件和当前瓶颈路径。
5. 右侧详情抽屉：点击容量塔后显示任务占用、上下游约束、等待时间和状态解释。

## 容量塔

每个并发池对应一根固定宽度的 ECharts 竖向堆叠柱：

- 塔内按配置上限绘制刻度，运行槽从底部向上填充。
- 空闲容量使用 ECharts 柱背景保持浅灰透明状态。
- 正常负载使用青绿色，70% 以上使用琥珀色，满载且存在排队时使用红色。
- 运行段使用状态色，排队段直接堆叠在同一根柱的顶部并使用灰色；排队段不计入容量上限。
- 通过每根柱对应的虚线 `L<limit>` 刻度区分配置容量和超出容量的等待段。
- 槽位释放时，灰色堆叠段收缩，运行段同步变化，ECharts 负责平滑过渡。
- `global_pipeline` 等未接线配置使用虚线空心塔，并显示“未接入”，不生成伪造负载。
- `task_extraction` 显示配置容量，同时以注记说明当前实现的单文件观测并发为 1。

## 模拟数据

原型内置覆盖不同状态的初始数据：

- 正常、空闲、高负载、满载排队、暂时无请求、未接入。
- 十个统一并发配置：三个模型通道、三个业务阶段、三个单任务限制，以及独立的 `global_pipeline` 管线调度状态。
- 活动任务包含文件名、阶段、占用时长和来源池。
- 每 1.4 秒执行一次模拟 tick，在合理边界内改变运行数、排队数、完成数、等待时间和压力历史。
- 模拟数据保持约束合法：运行数不超过容量，排队数不为负，未接入池始终不产生运行任务。

## 动画

- 数据变化由 JavaScript 更新状态，ECharts 负责柱图和曲线的平滑过渡。
- 柱体使用平滑高度过渡和低强度更新，不使用剧烈闪烁。
- 数值变化使用短暂强调，不造成布局位移。
- 压力曲线连续向左推进。
- 用户启用“减少动态效果”时关闭流光和位移动画，仅保留即时状态更新。

## 交互

- 暂停/继续：停止或恢复模拟 tick，连接状态同步改变。
- 手动刷新：立即产生一轮新状态。
- 点击容量塔：打开详情抽屉，并高亮与其关联的上游或下游池。
- 点击空白处或关闭按钮：收起详情抽屉。
- 键盘用户可聚焦容量塔并通过 Enter/Space 打开详情。

## 响应式与可访问性

- 桌面端同屏展示全部容量塔；窄屏下主画布允许横向滚动，容量塔不压缩变形。
- 所有颜色状态同时配合文字、数值或图形样式，不能只依赖颜色判断。
- 动态数字使用 `aria-live="polite"`，按钮具备明确名称和焦点样式。
- 页面不依赖网络资源，复用仓库内的字体和 Lucide 图标资源。

## 原型边界

- 不接入真实后端，不新增 API、SSE 或 WebSocket。
- 不修改现有 `ui/index.html`、业务逻辑或配置。
- 后续真实接入时，模拟器可以替换为只读状态快照与 SSE 增量事件，视觉组件无需重做。

## 验收标准

1. HTML 可直接打开，无需启动开发服务器。
2. 页面加载后所有容量塔均非空白，模拟数据持续变化。
3. 运行容量、灰色排队条、空闲槽和未接入状态能够明确区分。
4. 暂停、继续、刷新和详情抽屉可用。
5. 1440x900、1280x720 和 390x844 视口下无文本遮挡或控件重叠。
6. 浏览器控制台无 JavaScript 错误。
