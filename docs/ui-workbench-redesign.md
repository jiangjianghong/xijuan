# 工作台界面重构与验收记录

日期：2026-11-17

## 设计方向

采用 framed-sheet 布局：青灰底框、白色内容画布、墨色文字和低饱和青绿状态色。导航固定在左侧，顶部承载当前项目与文档类型，内容按业务模块展开。字体沿用项目已有的本地 Nunito，中文使用系统字体回退，不增加远程字体或动画依赖。

视觉设计使用 design-taste-frontend 的应用界面流程，方向种子为 553280740。产品识别元素来自 PDF 文档本身：叠纸上传图形、文档轮廓标记，以及与真实队列联动的六阶段流程。没有改动后端接口或处理管线。

## 页面与交互

- 工作空间：文件处理、规则配置、流式演示、现有智能体入口。
- 洞察与运行：数据统计、并发运行台、调用日志、实时日志。
- 开发与管理：API 手册、系统设置。项目与文档类型管理保留在顶部。
- 文件页按上传、处理中队列、六阶段流程、文档库组织。手机端文件行同时展示名称、状态、大小、时间及操作。
- 全局统计与日志显示明确的范围说明，避免将类型选择器误认为这些页面的过滤条件。
- Ctrl/Cmd+K 可搜索并跳转模块。页面地址支持 `?page=...`、浏览器前进后退和各页滚动位置恢复。
- 轮询刷新保留当前列表勾选；改变类型、筛选或分页后重置选择。较晚返回的旧列表请求不会覆盖新视图。
- 支持同一份文件重复选择、上传区键盘操作、详情弹窗 Escape 退出和焦点返回。
- 增强下拉控件补齐可访问名称、listbox/option 语义，以及 Enter、空格、方向键、Tab、Escape 操作。

实际代码中仍存在项目选择器和项目管理，所以此次按现有运行代码保留；没有依据旧说明删除这一功能。原有智能体 Beta 标签不换行的调整也保留。

## 动效

| 场景 | 行为 |
| --- | --- |
| 模块导航 | 选中底板连续滑动，420ms 缓出 |
| 页面切换 | 标题与内容错开 35ms 入场，340ms 位移与透明度过渡 |
| 上传区 | 双层纸张在悬停、键盘聚焦和拖入时轻微展开，480ms 弹性曲线 |
| 按钮与图标 | 轻微抬升、按下回弹、方向图标位移 |
| 下拉与弹窗 | 透明度和小幅位移过渡，明确浮层层级 |
| 队列 | 仅有任务时显示状态呼吸点；列表轮询不重复入场 |
| 手机侧栏 | 滑入、背景遮罩、焦点约束和 Escape 关闭 |

遵循系统减少动态效果偏好；切换偏好时取消正在运行的页面动画。没有引入动画库。

## 验证结果

- JavaScript 回归：`node --test tests/js/*.test.js tests/ui/*.test.cjs`，79 项通过。
- Python 前端契约：设置入口、运行台、上传参数弹窗三个测试文件，13 项通过。
- 独立 Edge 浏览器：1440、768、390px 均通过。覆盖模块导航、无页面级横向溢出、调用日志展开及结果弹窗、快捷导航、浏览器历史、筛选、勾选保留、详情焦点、重复文件选择、类型管理、系统设置和减少动态效果。
- 另由只读审查确认 320px 无页面级横向溢出；审查发现的弹窗快捷键冲突、手机导航焦点丢失及下拉空格滚动问题已修正。
- 视觉检查在三个标准宽度均为 0 FAIL。保留的 WARN 为禁用按钮/少量次要标签的对比度和较高的信息密度；正文、文件名及主要操作可读。样式词法检查的阴影/模糊警告包含 `none` 规则及真实浮层，不代表页面使用玻璃卡片。
- `git diff --check` 与修改脚本的语法检查通过。

验证使用本地固定样例数据，未向真实数据库、模型或业务写入接口发送请求，未进行真实 PDF 六阶段端到端联调。已有 `tests/test_rule_debug_reextract_ui.py` 的 6 项测试因其 Node VM 未提供 `window` 而失败；相关测试和 `ruleConfig.js` 均与 HEAD 一致，本次没有修改它们。

## 预览与重跑

运行应用后，在 `/ui/` 使用 Ctrl+F5 刷新即可加载新静态资源。

独立只读预览：

```powershell
node tests/browser/workbench_fixture.cjs
```

默认监听 `127.0.0.1:4173`，只使用六份样例文档和固定配置。非 GET/HEAD 请求返回 405；该服务不能用于验证真实保存、删除或上传。

浏览器回归：

```powershell
# 需要当前 Node 环境可以解析 playwright，并安装 Microsoft Edge。
node tests/browser/workbench_visual.cjs
```

浏览器截图输出在 `.taste-skill/after/`，前后测量结果在 `.taste-skill/before/`、`.taste-skill/inspected/`。这些生成资料已加入 Git 忽略列表；业务代码与可重复执行的测试保留在源码目录。

## 改动位置

- `ui/index.html`：导航、范围选择、页面外壳、文件页层级与快捷导航弹窗。
- `ui/css/workbench.css`：统一配色、布局、响应式和动效。
- `ui/js/workbench.js`：外壳状态、快捷键、焦点、范围提示及动效协调。

- `ui/js/customSelect.js`：控件名称、读屏语义及键盘行为。
- `tests/browser/workbench_fixture.cjs`、`workbench_visual.cjs`：独立预览和浏览器回归。
